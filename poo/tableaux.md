## Tableaux de longueur finie

En Java, il est possible de créer des vrais tableaux comme on les a définit l'année dernière : **avec une longueure (dé)finie**.

Ces tableaux sont les tableaux par défaut sur Java. Le type est noté `<type>[]` avec n'importe quel type comme les `int`, `String`, etc.

Pour le créer, il faut définir sa longeur et utiliser le mot clef `new`. On le fait de la manière suivante :

```java
// Définir un tableau de 10 entiers
int[] tab = new int[10]
// Définir un tableau de 12 str
String[] tab = new String[12]
```
