# 💸 Introduction

Pourquoi la croissance économique nous obsède autant ?

## Rappels

Comment mesurer la croissance économique ? On regarde l'évolution du PIB réel **sur le long terme**. Le PIB est un indicateur **comptable**. Il existe trois approches pour le calculer :

1. **Production:** $\sum$ Valeurs Ajoutés (brut) + TVA (net) + Taxes à l'importation + Subv. à l'exportation
2. **Revenu:** Rémunération du travail + Excèdant Brut d'Exploitation (Profit) + revenu mixte brut + taxes - subv
3. **Dépense:** $C + I + G + (X - M)$ 

Piège malthusien

La fin de la faim. Sortie de la famine (même si existe toujours)

Lien bien être -> croissance

Donc l'augementation du PIB entraine du bien être. Il faut donc continuer la croissance pour ne pas perdre cette abondance. **C'est pour cette raison que nous sommes croissantistes.**
